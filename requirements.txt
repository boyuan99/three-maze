# Runtime dependencies of the Python backend (backend/, experiments/), pinned exactly.
# Needs Python >= 3.11 (numpy 2.3); developed and tested with Python 3.12.
#
# `npm install` puts these into .venv (setup/setup-python.js). For the tests, install
# requirements-dev.txt instead.
#
# Every package is pinned, including those that only nidaqmx pulls in. A rig must get the same
# packages the tests ran against, and nidaqmx 1.3.0 asks for nitypes>=0.1.0dev10, a requirement
# that admits pre-releases: unpinned, a fresh install takes whatever development build of nitypes
# is newest that day. Pin released versions only: a development build can be removed from PyPI.
#
# To upgrade: change a pin, install into a new venv, run the tests (python -m pytest), then copy
# the other versions from `pip freeze`. The pins come from a Windows venv; on Linux nidaqmx also
# pulls in `distro`, which is not pinned here.
